# Pilot Specialty Evidence Questionnaire

**Version:** 0.1  
**Status:** Draft for field use

## Respondent Types

Use adapted versions for:

- local doctors;
- facility clinical leads;
- diaspora consultants;
- NGO/partner representatives.

## A. Clinical Need

1. Which specialist decisions are most difficult to access currently?
2. How often do you need senior specialist input?
3. Which cases are commonly referred because specialist input is unavailable?
4. Which cases are currently discussed informally by phone/WhatsApp?
5. Which specialty gap causes the most avoidable delay?

## B. Case Suitability

1. Can the case usually be described using history, examination, results, and images?
2. How often is direct specialist physical examination essential?
3. How often is an immediate emergency response required?
4. Can useful advice normally wait 4–6 hours for priority or 24–48 hours for routine cases?

## C. Information Availability

1. What investigations are routinely available?
2. Can X-rays/ECGs/photos/results be captured digitally?
3. Typical file sizes/formats?
4. Are there diagnostic tools that are usually unavailable?

## D. Connectivity

1. Typical device used?
2. Mobile network availability?
3. How often is connectivity unavailable?
4. Typical time until connectivity returns?
5. Is Wi-Fi available at facility?
6. Can files be uploaded reliably?

## E. Workflow and Adoption

1. How long could a doctor reasonably spend submitting a case?
2. What would make users return to WhatsApp instead?
3. Who could act as facility coordinator?
4. Are doctors willing to record outcomes after advice?

## F. Volume

1. Approximate cases per week needing specialist input?
2. Seasonal variation?
3. Likely percentage suitable for remote review?

## G. Outcomes

1. What outcome can be measured within days/weeks?
2. Can referral avoidance be tracked?
3. Can management change be recorded?
4. Is patient follow-up feasible?

## H. Safety

1. What cases should never be submitted to Sanad?
2. What red flags require local emergency pathways?
3. What are the biggest risks of remote advice in this specialty?

## I. Consultant Supply

For diaspora consultants:

1. hours/month available;
2. preferred case volume;
3. response windows;
4. registration jurisdiction;
5. indemnity constraints;
6. willingness to work asynchronously;
7. reasons likely to decline cases.

## Required Expert Review

- Clinical Governance
- relevant specialty lead
- Public Health/Evaluation

Required before final specialty scorecard approval.
