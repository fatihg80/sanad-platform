# Pilot Operations Runbook

**Version:** 0.1  
**Status:** Draft

## 1. Purpose

Define how the live pilot is operated day to day.

## 2. Daily Operational Checks

- platform health;
- queue health;
- notification failures;
- cases awaiting assignment;
- priority cases;
- consultant availability issues;
- unresolved operational incidents.

## 3. Case Routing

Coordinator should:

1. review submitted case operational metadata;
2. confirm specialty;
3. identify eligible consultant;
4. assign;
5. monitor acceptance;
6. reassign when policy requires.

The coordinator should see the minimum clinical information needed for the role.

## 4. Priority Workflow

- priority queue checked frequently during service hours;
- missed assignment threshold triggers alert;
- approaching target triggers escalation;
- breach documented.

## 5. Outage Workflow

If platform outage:

1. confirm outage;
2. publish internal status;
3. activate approved fallback process if thresholds met;
4. record fallback cases/interactions;
5. reconcile after restoration.

## 6. Consultant Unavailability

- mark unavailable;
- reassign outstanding case if necessary;
- update rota/availability;
- investigate repeated capacity gaps.

## 7. User Support

Support categories:

- login/access;
- verification;
- case workflow;
- upload/connectivity;
- notification;
- clinical-governance query;
- security/privacy incident.

Clinical questions must not be handled as ordinary technical support.

## 8. Daily Handover

If coordinators work in shifts, handover should include:

- unassigned cases;
- priority cases;
- breached targets;
- incidents;
- outages;
- consultant capacity issues.

## 9. Weekly Review

Review:

- volume;
- response performance;
- failed/abandoned cases;
- support issues;
- incidents;
- user feedback;
- connectivity failures.

## 10. Monthly Governance Review

Include:

- clinical audit;
- incidents/near misses;
- complaints;
- consultant retention;
- workflow changes;
- security/privacy events;
- evaluation metrics.

## 11. Escalation Contacts

Before pilot maintain current contacts for:

- project lead;
- clinical governance lead;
- specialty lead;
- duty coordinator;
- technology/security;
- legal/privacy;
- partner facility;
- hosting/vendor support.

## 12. Runbook Maintenance

Every meaningful operational incident should test whether this runbook requires revision.
