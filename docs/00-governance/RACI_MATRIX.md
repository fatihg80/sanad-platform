# RACI Matrix

**Version:** 0.1  
**Status:** Draft

Legend:

- **R** Responsible
- **A** Accountable
- **C** Consulted
- **I** Informed

| Activity | Project Lead | Clinical Governance | Specialty Lead | Technology Lead | Operations | Legal/Privacy | Research/Evaluation |
|---|---|---|---|---|---|---|---|
| Product scope | A | C | C | C | C | I | C |
| Pilot specialty | C | A | R | C | C | I | C |
| Clinical template | I | A | R | C | C | C | C |
| Clinical safety | I | A/R | C | C | C | C | I |
| Architecture | I | C | I | A/R | C | C | I |
| Security architecture | I | C | I | A/R | C | C | I |
| Data protection | I | C | I | C | I | A/R | C |
| Professional verification | I | A | R | C | R | C | I |
| Partner selection | A | C | C | C | R | C | I |
| Vendor selection | A | C | I | R | C | C | I |
| Evaluation protocol | I | C | C | C | C | C | A/R |
| Incident review | I | A/R | C | R for technical | R | C | I |
| Go-live decision | A | A for clinical safety | C | A for technical readiness | A for operations | A for legal/privacy readiness | C |

Multiple accountabilities in the go-live row indicate cross-functional sign-off rather than one person owning all risk.
