# Project Manager Expert Engagement Action Plan

**Version:** 0.1  
**Status:** Active planning artifact

## Purpose

Translate the Expert Review Register into a practical engagement sequence for the Project Manager.

## Stage 1: Immediate Clinical Discovery

### Engage
- Clinical Governance Lead
- candidate specialty experts
- Public Health / Evaluation specialist

### Provide
- Founding Prospectus source notes
- PRD
- Clinical Workflow Specification
- Pilot Specialty Selection Framework
- Specialty Desk Evidence Review
- Specialty Evidence Questionnaire

### Required outputs
- evidence collection corrections;
- specialty exclusions;
- priority/emergency boundaries;
- shortlist of 2–4 specialties;
- field questions approved.

## Stage 2: Local Facility / Operations Discovery

### Engage
- facility clinical leads;
- local doctors;
- operations coordinator candidates;
- NGO/partner representatives.

### Provide
- Partner/Facility Selection Criteria
- Specialty Evidence Questionnaire
- generic Case Template Specification
- Scope Guardrails

### Outputs
- case-volume estimates;
- connectivity/device profile;
- available investigations;
- coordinator capacity;
- facility scorecards;
- workflow burden feedback.

## Stage 3: Vendor / Platform Discovery

### Engage
- Technology Lead / Architect
- Security Specialist
- Privacy/DPO
- Clinical representative
- Procurement/Commercial specialist

### Vendors/platforms
- Intelehealth
- VSee Enterprise
- CHT
- custom MVP reference option

### Outputs
- workflow demonstrations;
- technical architecture;
- offline behaviour;
- hosting/subprocessors;
- security documentation;
- Arabic/RTL evidence;
- data export;
- implementation estimate;
- commercial proposal/TCO.

## Stage 4: Legal and Regulatory Review

### Engage
- Sudan healthcare legal/regulatory expert
- relevant consultant-jurisdiction counsel
- Privacy/DPO
- sanctions/compliance specialist
- indemnity/insurance specialist
- corporate/tax adviser where needed

### Provide
- Legal and Regulatory Question Register
- Clinical Workflow
- Data Flow Inventory
- Hosting Options
- Legal Agreement Requirements
- Expert Review Register

### Outputs
- written legal advice;
- blocking/non-blocking classification;
- controller/processor model;
- consultant eligibility model;
- consent model;
- data transfer/hosting constraints;
- required contracts/insurance.

## Stage 5: Decision Closure

Project Manager convenes:

- Project Lead
- Clinical Governance
- Technology
- Security
- Privacy/Legal
- Operations
- Evaluation
- Commercial/Finance where relevant

Close:

1. Pilot specialty
2. Pilot facilities
3. Build / Buy / Partner
4. Hosting/data residency
5. Offline scope
6. Service hours/SLA model
7. Evaluation minimum dataset

## Stage 6: Pre-Go-Live Expert Reviews

- independent security assessment / penetration test;
- final clinical safety review;
- completed privacy/DPIA review;
- legal readiness;
- ethics determination where relevant;
- UX/accessibility field validation;
- infrastructure/SRE recovery review.

## Tracking Rule

Every expert engagement should produce a traceable record linked to:

- Expert Review Register ID;
- decision ID;
- relevant document;
- date;
- reviewer;
- result;
- conditions/actions.

A meeting alone does not close an expert review.
