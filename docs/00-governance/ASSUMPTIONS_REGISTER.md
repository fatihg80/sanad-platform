# Assumptions Register

**Version:** 0.1  
**Status:** Active

| ID | Assumption | Impact if False | Validation Path | Status |
|---|---|---|---|---|
| A-01 | Local doctors can access intermittent mobile internet | Core workflow fails | Needs assessment / field test | Open |
| A-02 | Consultants abroad are willing to join a structured rota | Capacity failure | Consultant survey | Open |
| A-03 | Provider-to-provider model is legally feasible | Pilot may be blocked | Legal/regulatory review | Open |
