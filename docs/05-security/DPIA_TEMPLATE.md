# Data Protection Impact Assessment Template

**Version:** 0.1  
**Status:** Template for qualified privacy/legal review

This template supports a future DPIA where required. It is not a completed legal assessment.

## 1. Project Description

- service purpose;
- users;
- jurisdictions;
- pilot scope.

## 2. Processing Description

For each activity:

- data collected;
- source;
- purpose;
- recipients;
- storage;
- retention;
- transfers.

## 3. Necessity and Proportionality

- why each data category is needed;
- alternatives considered;
- minimisation;
- user transparency;
- rights handling.

## 4. Risks to Individuals

Consider:

- clinical confidentiality;
- discrimination;
- professional harm;
- physical safety;
- location exposure;
- account compromise;
- re-identification;
- secondary use.

## 5. Controls

- access;
- encryption;
- minimisation;
- audit;
- offline controls;
- vendor controls;
- incident response;
- training.

## 6. Residual Risk

For each high risk:

- likelihood;
- impact;
- controls;
- residual level;
- risk owner;
- acceptance/escalation.

## 7. Consultation

Record consultation with:

- clinical governance;
- legal/privacy;
- facilities;
- users;
- regulator/data protection authority where required.

## 8. Approval

- privacy/legal owner;
- security owner;
- clinical owner;
- date;
- review trigger.
