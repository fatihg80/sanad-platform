# Pilot Go-Live Readiness Checklist

**Version:** 0.1  
**Status:** Draft

Pilot launch should not occur because a target date has arrived.

It should occur only when critical readiness conditions are met.

## Clinical

- [ ] Pilot specialty approved
- [ ] Case template approved
- [ ] Priority criteria approved
- [ ] Emergency boundary wording approved
- [ ] Clinical governance lead assigned
- [ ] Incident process approved
- [ ] Second-opinion process approved
- [ ] Safety hazard log reviewed and residual risks accepted

## Legal / Regulatory

- [ ] Professional practice model reviewed
- [ ] Consultant eligibility model reviewed
- [ ] Facility agreements executed
- [ ] Consultant agreements executed
- [ ] Data controller/processor roles confirmed
- [ ] Hosting/data transfer position approved
- [ ] Sanctions/payment process approved
- [ ] Indemnity/insurance position reviewed

## Privacy

- [ ] DPIA completed where required
- [ ] Retention schedule approved
- [ ] Access matrix approved
- [ ] Data minimisation reviewed
- [ ] Offline storage reviewed
- [ ] Third-party providers approved

## Technology

- [ ] Core workflow UAT passed
- [ ] Authorisation tests passed
- [ ] Security testing completed
- [ ] Object storage private
- [ ] Monitoring operational
- [ ] Backups operational
- [ ] Restore test passed
- [ ] Production secrets managed
- [ ] Deployment rollback/recovery plan tested

## Operations

- [ ] Partner facilities onboarded
- [ ] Coordinators trained
- [ ] Consultant rota sufficient
- [ ] Support model active
- [ ] Escalation contacts current
- [ ] Fallback channel approved
- [ ] Outage reconciliation process tested

## Evaluation

- [ ] Evaluation protocol approved
- [ ] Minimum dataset approved
- [ ] Ethics determination complete
- [ ] Baseline surveys ready
- [ ] Reporting validated

## Users

- [ ] Local doctors verified
- [ ] Consultants verified
- [ ] Training completed
- [ ] Competency check completed where required
- [ ] MFA/security onboarding completed

## Final Decision

- [ ] Clinical sign-off
- [ ] Technology/security sign-off
- [ ] Operations sign-off
- [ ] Legal/privacy readiness sign-off
- [ ] Project leadership go-live approval

Any unchecked blocker requires an explicit documented risk decision before launch.
